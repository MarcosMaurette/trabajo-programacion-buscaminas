# Cómo subir este README a GitHub

1. Descomprimí `minesweeper-readme-github.zip`.
2. Copiá `README.md` y la carpeta `imagenes/` a la raíz de tu repositorio.
3. Conservá la estructura de carpetas: las rutas de las imágenes son relativas y deben mantenerse.
4. En GitHub, elegí **Add file → Upload files** y subí el README junto con la carpeta `imagenes/` (o hacé commit desde Git).
5. Confirmá los cambios. GitHub renderizará las imágenes dentro del README automáticamente.

No cambies los nombres de los archivos de `imagenes/` salvo que también actualices las rutas dentro de `README.md`.
